🚀 Getting Started

Follow these three easy steps to keep your game saves safe.

📥 Step 1 – Download and Run

Visit this link to download the application: github.com/lucas2010m/save-backup-manager/releases

Click the newest version at the top. The download starts automatically. No registration, no payment, no hidden steps.

Once the download is finished, open the downloaded file and the program starts right away. A green shield icon appears in your taskbar as well.

🛡️ Step 2 – Add a New Game

On the main screen, click the big button that says "＋ New Game". A friendly panel opens.

Write a name you understand, like "Zelda – Week 3" or "My Elden Ring Character". Click "Select Game Folder" and choose the save location on your computer. You can also let it search automatically—the app scans a list of known locations. Then just press "Save".

⏰ Step 3 – Configure Backups and Relax

Choose how often you want backups: when you start a game, every 30 minutes, or daily at a set time.

Enable "keep last 20 versions" to be able to go back to any past moment.

That is everything. Your game has a safety net whenever something goes wrong. If a file becomes corrupted after adding a mod, open the manager, select your game from the list, press "Restore", and pick a prior version.

❓ Frequently Asked Questions

🔹 I am not a technical person. Can I really use this?

Yes. That is why it was built. You do not need to see any file path or type a command line. If you can use the mouse and read words, you are good.

🔹 Will this mess up my games?

No. The program only writes copies. It never modifies your original saves or moves them. Its only job is to create duplicates in a hidden folder you can access.

🔹 Does it use the internet or upload data?

Never. This tool works entirely offline. No analytics, no telemetry, no email requests. If you are offline, everything still works perfectly.

🔹 My game saves into multiple folders. What happens?

No worries. You can attach more than one folder to each game profile. The manager backs up all of them at the same time under that single friendly name.

🔹 What if a save file becomes huge?

The app has optional compression. It can pack your saves into archive files that take half or even a third of the original space. You can choose between compression and pure copying speed.

🔹 Can I use it on multiple game saves at once?

Absolutely. Hundreds of games. Each game gets 'Backup Now', 'Restore', and 'Settings' buttons. There is also "Backup All" button at the top of the page for one-click protection.
